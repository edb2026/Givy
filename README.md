# GivyRewards

A simple web app to give away your stuff and get rewarded.

**Features:**
- Post items you want to give away (furniture, household items, office equipment, etc.)
- Free pickup service
- Rewards system (Gold, Diamond, Champion levels)
- Beautiful mobile-friendly design
- Saves your requests locally in the browser

### How to run locally
Just open `index.html` in any browser — no server needed.

### Deploy to GitHub Pages (Free)
1. Create a new repository on GitHub (recommended name: `givyrewards`)
2. Upload `index.html` and `README.md` to the repository
3. Go to **Settings → Pages**
4. Under "Source", select **Deploy from a branch** → `main` → `/ (root)`
5. Click **Save**

Your site will be live at:  
`https://yourusername.github.io/givyrewards`

Enjoy giving and getting rewarded! ✨
